# AI Cognitive Assessment Platform — Patent Edition Prototype

This prototype implements the complete 15-step workflow as an integrated demonstrator.

1. Student Authentication — registration/login with MongoDB and offline demo fallback.
2. Identity Verification — live camera access, one-face enforcement and confidence output.
3. Device Validation — camera, microphone, secure context, storage, network and screen checks.
4. Behavioral Baseline — mouse, reaction-time and typing calibration.
5. Adaptive Initialization — role, language, difficulty and competency blueprint.
6. AI Question Engine — competency-tagged question graph and difficulty-aware selection.
7. Multimodal Collection — MCQ, voice transcript, camera, interaction and timing data.
8. Real-Time Monitoring — live face count, tab switching and window-focus events.
9. Cognitive Intelligence — rules-based mapping to knowledge, reasoning and adaptability.
10. Dynamic Difficulty — difficulty changes using correctness, speed and confidence.
11. Knowledge Evaluation — correctness, Bloom level, competency coverage and partial reasoning.
12. Behaviour & Confidence — voice coverage, fluency, attention and confidence indicators.
13. Integrity & Fraud Intelligence — multi-face, missing face and focus-loss risk fusion.
14. Final AI Decision — explainable recommendation based on weighted indicators.
15. Personalized Report — cognitive profile, strengths, gaps, roles and learning roadmap.

## Important scientific limitation
This is a patent-oriented functional prototype. Cognitive, confidence and behavioral scores are transparent rules-based indicators, not medical or psychological diagnoses. Production deployment requires validated datasets, bias testing, informed consent, privacy controls and trained/validated models.
